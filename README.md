# PolarFire SoC FPGA Linux Examples

This repository contains a number of example applications/solutions that can be used to
explore the features of the PolarFire SoC Video Kit.
These examples will be automatically included as part of the Video kit
Yocto images, in the `/opt/microchip/` directory.
These images will contain both the source code for the examples as well as
precompiled binaries where possible.

## Hardware Requirements

PolarFire SoC Video Kit (MPFS250TS-1FCG1152I)

## Pre-requisites

Before running any of these example applications, set up the Video kit and
ensure Linux can be booted as explained in the
[MPFS-VIDEO-KIT][1] document.

[1]: https://mi-v-ecosystem.github.io/redirects/boards-mpfs-sev-kit-sev-kit-user-guide
